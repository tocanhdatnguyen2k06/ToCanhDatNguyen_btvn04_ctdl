## Hướng dẫn chạy code

### 1. Python
Chạy trực tiếp file script bằng lệnh:
python ten_file.py

### 2. C++
Biên dịch và chạy bằng G++ (trên Windows PowerShell):
g++ ten_file.cpp -o ten_file
./ten_file

### 3. Julia
Chạy file script Julia bằng lệnh:
julia ten_file.jl
